## 📖 Project Overview

This project presents an interactive Tableau dashboard designed to analyze website traffic, user engagement, and conversion performance across multiple traffic sources and marketing campaigns.

The dashboard enables stakeholders to monitor key performance indicators (KPIs), evaluate campaign effectiveness, identify regional trends, and support data-driven marketing decisions.

---

## 🎯 Business Problem

Digital businesses rely on website traffic and conversions to measure marketing success. However, understanding which channels, campaigns, and regions contribute most to user acquisition and conversions can be challenging.

This dashboard provides a centralized view of website performance, enabling faster and more informed business decisions.

---

## 🎯 Objectives

- Monitor website traffic performance
- Analyze conversion rates by traffic source
- Evaluate campaign effectiveness
- Track user acquisition and returning users
- Identify regional performance trends
- Support marketing optimization through interactive visualizations

## 📈 Key Insights

- Organic traffic generated the highest number of sessions.
- Direct traffic achieved the highest conversion rate.
- Website traffic showed noticeable weekly fluctuations.
- Chrome was the most widely used browser.
- Android and Windows accounted for the majority of users.
- Conversion performance varied significantly across different states.
